# DeFiNook

DeFiNook is a decentralized, microservices-based framework that enables real-time, event-driven processing and auto-scaling for scalable financial applications.

DeFiNook is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DeFiNook.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DeFiNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
